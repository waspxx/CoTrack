{{ _('Performance Metrics') }}

{{ _('Real Return:') }} {{ _('Portfolio return calculated as (Current Value - Total Cost) / Total Cost, where Total Cost = Avg Price × Shares for each ETF. {{ _('Annualized Return:') }} {{ _('Compound Annual Growth Rate (CAGR). Represents the average annual growth rate of the portfolio over the entire period considered. Shows what constant annual return you would have achieved if the portfolio had grown evenly each year.') }}

{{ _('Capital Metrics') }}

{{ _('Value:') }} {{ _('Current value of the portfolio based on current market prices.') }}

{{ _('Net Invested Capital (Carrying Value):') }} {{ _('Total invested calculated as Avg Price × Shares for each ETF in the portfolio, then summed. Represents the total cost of currently held positions. Can be greater than net cash flow (Purchases - Sales) if you reinvested profits from previous sales.') }}

{{ _('Total Gain:') }} {{ _('Calculated as (Current Value - Total Cost) + Dividends. Represents the overall gain of the portfolio: capital gain on currently held positions plus dividends received.') }}

{{ _('Dividends:') }} {{ _('Total dividends and coupons received during the period.') }}

{{ _('Volatility (Annual):') }} {{ _('Measures the intensity of the portfolio value fluctuations. Calculated as the standard deviation of daily returns, annualized (assuming 365 calendar days).') }}

{{ _('Sharpe Ratio:') }} {{ _('Measures the risk-adjusted return. Calculated as the ratio between the average return and volatility, indicating how much extra return is obtained for each unit of risk. A value above 1 is generally considered good.') }}

ℹ️ {{ _("What is TWR and why is it different from real gain?") }}

{{ _('What is TWR?') }}

{{ _('TWR (Time-Weighted Return) measures the portfolio performance ignoring when you deposited or withdrew money. It calculates the return as if every euro had been invested from the beginning.') }}

{{ _('Why is TWR higher than real gain in a savings plan (PAC)?') }}

{{ _('In a savings plan you invest gradually over time, but TWR calculates as if everything was invested from the start. Your real gain is lower because part of the capital entered later, when prices had already risen. So TWR shows the portfolio performance, while the real gain shows how much you actually earned.') }}

{{ _('Why is it useful?') }}

{{ _('It allows you to compare the portfolio performance with benchmarks or other investors, without being influenced by the timing of your investments.') }}
